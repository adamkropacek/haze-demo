Wetterstation Haze: Stalllüftung ohne Sorgen!

Ein hochwertiges Lüftungssystem für Ställe ist gleich aus mehreren Gründen wichtig - es sorgt für gutes Tierwohl, beeinflusst die Verteilung des natürlichen Lichts in den Ställen, verringert die Luftgeschwindigkeit und reduziert die Zahl der Vögel, die in das Gebäude einfliegen. Ideal ist dabei, wenn dieses System von selbst funktioniert, ohne dass Sie sich darum kümmern müssen - und genau das leisten die Wetterstationen von Haze.

Während sich das Wetter ändert, können Sie ruhig bleiben. Eine hochwertige Wetterstation überwacht nämlich die Witterungsbedingungen für Sie und passt die Lüftungssysteme in den Ställen automatisch daran an. Dabei kann sie auf wechselnden Wind, Regen und wechselnde Temperaturen reagieren.

Sobald Wind aufkommt, schließt das elektronische System die Seitenplanen schrittweise, zuerst zu einem Drittel, dann zu zwei Dritteln, und schließlich vollständig. In der Wetterstation sind nämlich verschiedene Windgeschwindigkeitsstufen hinterlegt, damit das System weiß, welche Intensität dem Schließen auf eine bestimmte Stufe entspricht. Ebenso ist im System eine Trägheit der Reaktion auf das Wetter eingestellt, sodass immer eine gewisse Zeit vergeht, bevor die Wetterstation ein Signal zur Änderung der Einstellung ausgibt. Das schont wiederum die Antriebseinheiten und verringert ihren Verschleiß.

Ähnlich reagiert das elektronische System auch auf Regen und wechselnde Temperaturen. Ist an die Wetterstation auch eine Firstlüftung angeschlossen, schließt das System sie bei Regen vollständig. Bei der Temperatur wiederum kann es zum Beispiel langsam laufende Ventilatoren oder Beschattungssysteme in Gang setzen; es lassen sich auch unterschiedliche Konfigurationen für Sommer- und Winterwetter einstellen.

Zur Wetterstation gehören zwei Windgeschwindigkeitssensoren (je einer auf jeder Seite des Stalls), ein beheizter Regensensor, der auch Schneefall erkennt, sowie ein bis drei Temperatursensoren. Alle erfassten Informationen laufen anschließend im Hauptschaltschrank zusammen, der sie auf einem übersichtlichen Display anzeigt.

An die Wetterstation können Sie alle Varianten der Seitenlüftungssysteme anschließen, die unser Unternehmen anbietet. Auf Kundenwunsch können wir auch weitere Elemente in das System einbinden, zum Beispiel ein elektronisches Steuerungssystem für die Firstlüftung, die Steuerung der Ventilatoren im Stall oder eine Beschattung gegen direkte Sonneneinstrahlung. Bei der Funktion "Winterbetrieb" überwacht das System die Temperatur in den Ställen und schließt die Planen in die gewünschte Position, sobald die Temperatur unter den eingestellten Wert fällt. Dadurch verhindert es das Eindringen von Frost in die Ställe, und Sie sparen anschließend Geld für die elektrische Energie, die zum Erwärmen des Wassers in den Tränken verbraucht wird. Die entgegengesetzte Funktion "Sommerbetrieb" ermöglicht es wiederum, die Seitenwände an schwülen Sommertagen zu öffnen.

Praktisch ist auch die Funktion zur Überwachung der Lee- und Luvseite. Das elektrische System erkennt selbst, von welcher Seite der Wind stärker weht, und passt die Öffnung der Planen entsprechend an - auf der Leeseite lässt es sie teilweise geöffnet, während es sie auf der Luvseite schließt. So sichern Sie sich eine ausreichende Lüftung der Ställe auch dann, wenn draußen gerade extremes Wetter herrscht.

Wie genau die Station arbeitet und wie das aktuelle Wetter ist, können Sie bequem im Internetbrowser auf Ihrem Computer verfolgen. Um mehr müssen Sie sich nicht kümmern - unsere Fachleute stellen das elektronische System so ein, dass es den konkreten Standort der Ställe berücksichtigt (Bergregionen haben zum Beispiel oft einen anderen Wetterverlauf als tiefer gelegene Gebiete). Sobald im laufenden Betrieb die letzten Kleinigkeiten abgestimmt sind, ist das System vollständig autonom und erfordert keine Bedienung. Die Wetterstation Haze hält in Ihren Ställen optimale Bedingungen aufrecht, während Sie sich in Ruhe anderen Arbeiten widmen können!
